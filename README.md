# Dual Output Power Supply PCB

A compact dual output regulated power supply PCB designed using KiCad.  
Designed and developed a compact dual-output regulated power supply PCB using KiCad. The circuit converts DC input voltage into stable 5V and 3.3V outputs using AMS1117 voltage regulators. Created schematic design, PCB layout, copper routing, ground plane, and 3D visualization for hardware implementation.
This project provides stable 5V and 3.3V outputs using AMS1117 voltage regulators for embedded systems and electronics applications.

## Features
- Dual regulated outputs: 5V and 3.3V
- AMS1117-5.0 and AMS1117-3.3 regulators
- Compact PCB layout
- Power indication LEDs
- Copper fill and optimized routing
- 3D PCB visualization
- DC barrel jack input with fuse protection

## Software Used
- KiCad

## Project Files
- Schematic Design
- PCB Layout
- 3D PCB View
- KiCad Source Files

## Applications
- Embedded systems
- Microcontroller projects
- Sensor interfacing
- Electronics prototyping
- Low-power hardware systems
